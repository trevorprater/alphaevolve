Hello Claude, let's implement the `DiffApplier` module.

**Role:** You are an expert Python developer specializing in text manipulation and code processing.
**Task:** Implement the `DiffApplier` utility to apply LLM-generated diffs to code.

**File:** `alpha_evolve/diff_applier.py`

**Request:**
Define a class `DiffApplier` (or a set of static utility functions if preferred, but a class might be cleaner for future extensions):

1. Implement a method `apply_diff(self, parent_code_string: str, diff_string: str) -> str`:
    - This method should parse the `diff_string` which is expected in the format:

      ```
      <<<<<<<< SEARCH
      [original code block to be found and replaced]
      ========
      [new code block to replace the original]
      >>>>>>>> REPLACE
      ```

    - It needs to extract the `original_code_block` and `new_code_block` from the `diff_string`. Handle potential parsing errors (e.g., missing markers).
    - It must find the _first occurrence_ of the exact `original_code_block` (including leading/trailing whitespace as provided in the diff) within the `parent_code_string`.
    - If found, it should replace that occurrence with `new_code_block` and return the modified `parent_code_string`.
    - If the `original_code_block` is not found in `parent_code_string`, it should raise a custom `DiffApplicationError` (define this simple exception class in the same file) or return the `parent_code_string` unchanged with a warning/log (let's go with raising an error for clarity).
    - Consider edge cases: empty `original_code_block`, empty `new_code_block`.
2. Implement a method `apply_full_block_replace(self, parent_code_string: str, evolvable_block_id: str, new_block_code_string: str) -> str`:
    - This method is for cases where the LLM generates a complete replacement for an entire evolvable block.
    - It should find the evolvable block in `parent_code_string` identified by `# EVOLVE-BLOCK-START <block_id>` and `# EVOLVE-BLOCK-END <block_id>`.
    - It should replace the entire content _between_ these markers (inclusive of any original content, exclusive of the markers themselves) with `new_block_code_string`.
    - If the specified `block_id` is not found, raise a `DiffApplicationError` or similar.

Ensure clear docstrings, type hints, and robust error handling. Regular expressions might be helpful for parsing the diff string and finding the evolve blocks.
